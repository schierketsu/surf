## Сёрф

- `figma/` — плагин Figma (`manifest.json`, `figma.js`), ресурсы и схемы.
- `app/` — React приложение с canvas и переключателем темы.
- `презентация.pptx` — презентация проекта.

UI kit: https://clck.ru/3WcFW7

Запуск приложения:

```bash
cd app
npm install
npm run dev
```

Откройте http://127.0.0.1:5173/ и оставьте терминал запущенным.
